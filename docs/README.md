# Документация SukaRiseBot

SukaRiseBot — асинхронный типизированный Python SDK для ботов SukaRise. Эта документация
написана для тех, кто хочет не только запустить бота, но и понимать, как всё устроено.

## С чего начать

Если вы здесь впервые, читайте по порядку:

1. **[Быстрый старт](quickstart.md)** — создать бота в личном кабинете, дать ему права в
   комнате и запустить первый скрипт.
2. **[Обработчики событий](handlers.md)** — что бот может слушать: чат, входы, чаевые,
   личные сообщения и другое.
3. **[Справочник действий `BotAPI`](api.md)** — что бот умеет делать: говорить, ходить,
   модерировать, давать чаевые, отвечать в личных сообщениях.
4. **[Команды, таймеры и диалоги](commands.md)** — `!команды`, периодические задачи и
   вопросы с ожиданием ответа.

## Принципы SDK

- **Строгая типизация.** Все публичные функции и данные типизированы; SDK проходит
  `mypy --strict` и `pyright` в режиме `strict`. Данные, которые вы получаете, неизменяемы.
- **Ошибки там, где вы их допустили.** Аргументы проверяются до отправки: неверный вызов даёт
  `InvalidArgument` в вашей строке кода, а не отказ сервера позже.
- **Бот подчиняется тем же правилам, что и человек.** У бота нет «чёрного хода»: права
  модератора, лимиты и правила комнаты те же.
- **Ваш код не ломает бота.** Исключение в обработчике, команде или таймере не останавливает
  бота: оно попадает в `on_error`, а бот продолжает работать.
- **Подписка только на нужное.** Бот получает лишь те события, для которых вы написали
  обработчик.
- **Совместимость с Highrise.** Названия полей и формат кадров совпадают с официальным
  SDK Highrise, поэтому знакомый код читается так же.

# Быстрый старт

За десять минут вы создадите бота в личном кабинете, дадите ему права в комнате и
запустите первый скрипт. Если что-то не получилось, загляните в
[«Ошибки и отказы»](errors.md) и [FAQ](faq.md).

## Что понадобится

| Что | Зачем |
|---|---|
| Аккаунт SukaRise с активной подпиской **PREMIUM** | Боты — функция PREMIUM. Без подписки ключ бота не создать, а созданный ключ перестаёт подключаться (после продления снова работает). |
| Комната, в которой вы можете добавлять дизайнеров и модераторов | Бот входит в комнату только по приглашению владельца. |
| Python **3.13** или новее | SDK использует возможности последних версий языка. |

## Шаг 1. Установите SDK

```bash
git clone <адрес репозитория SukaRiseBot>
cd sukarisebot
python -m venv .venv
```

Активируйте окружение и установите пакет:

```bash
# Linux и macOS
source .venv/bin/activate
# Windows (PowerShell): .venv\Scripts\Activate.ps1
pip install -e .
```

Единственная зависимость — `aiohttp`; она подтянется сама. Проверка:

```bash
python -c "import sukarisebot; print(sukarisebot.__version__)"
```

## Шаг 2. Создайте бота в личном кабинете

1. Откройте личный кабинет SukaRise и перейдите в раздел **«Боты»**.
2. Введите имя бота в поле **«Имя бота»** и нажмите **«Создать бота»**. Имя —
   это логин бота в игре, оно проверяется как ник игрока: от 3 до 32 символов,
   латиница, цифры и `_ . -`, и оно не должно быть занято.
3. Кабинет покажет **токен** (строка вида `srbot_…`) и предложит его скопировать.
   Сохраните токен сразу: **больше он показан не будет**. Если токен потерян,
   нажмите **«Новый токен»** — старый перестанет работать.
4. В строке бота появится **«логин в комнате»**: это имя, которое вы выбрали. Оно
   нужно для следующего шага.

Новый бот сразу выглядит как готовый персонаж: он получает внешность по полу
владельца (женскую или мужскую, а если пол в профиле не указан — мужскую), фон и
позу профиля. Одежду бота потом можно сменить из кода.

На одном аккаунте может быть до трёх ботов. Кнопки **«Выключить»**/**«Включить»**
останавливают и возобновляют ключ, **«Удалить»** убирает бота навсегда.

> **Токен — это пароль бота.** Не публикуйте его в репозитории, чатах и скриншотах.
> Храните в переменной окружения или в файле, который не попадает в git. Если токен
> утёк, выпустите новый.

## Шаг 3. Дайте боту права в комнате

Бот — такой же участник комнаты, как человек, и подчиняется тем же правилам.

1. Откройте настройки своей комнаты.
2. Найдите бота по имени и добавьте его в **дизайнеры** комнаты. Свои боты
   показываются первыми в рекомендациях. Без этого бот не войдёт: сервер
   ответит, что боту нужны права дизайнера.
3. Если бот должен **модерировать** (`kick`, `ban`, `mute`) или **телепортировать**
   людей, добавьте его ещё и в **модераторы**. Права «дизайнер» для этого мало.

В одной комнате может находиться до трёх ботов одновременно.

## Шаг 4. Узнайте ID комнаты

Бот подключается к комнате по её идентификатору — строке вида `room-ee3c8c43fb41e0b0`.
Он указывается в `room_id` при запуске.

## Шаг 5. Напишите и запустите бота

Создайте файл `greeter.py`:

```python
from sukarisebot import Bot, Location, User


class Greeter(Bot):
    async def on_user_join(self, user: User, position: Location) -> None:
        await self.api.chat(f"Добро пожаловать, {user.username}!")


if __name__ == "__main__":
    Greeter().start()
```

Токен и комнату удобно передавать через переменные окружения, чтобы они не
оказались в коде.

Linux и macOS:

```bash
export SUKARISEBOT_TOKEN="srbot_..."
export SUKARISEBOT_ROOM_ID="room-..."
python greeter.py
```

Windows, PowerShell:

```powershell
$env:SUKARISEBOT_TOKEN = "srbot_..."
$env:SUKARISEBOT_ROOM_ID = "room-..."
python greeter.py
```

Windows, cmd:

```bat
set SUKARISEBOT_TOKEN=srbot_...
set SUKARISEBOT_ROOM_ID=room-...
python greeter.py
```

Если нужен адрес шлюза, отличный от стандартного, задайте `SUKARISEBOT_URL`
(например, для тестового сервера). Токен, комнату и адрес можно также передать
аргументами: `Greeter().start(token="…", room_id="…", url="…")`.

Бот появится в комнате как игрок с флагом бота и значком бота, под именем, которое
вы ему дали, и поздоровается с каждым, кто войдёт. Остановить его можно через `Ctrl+C`.

Бота можно запустить и без собственного скрипта запуска — командой:

```bash
python -m sukarisebot greeter:Greeter --room room-... --token srbot_...
```

(`greeter:Greeter` — «модуль:Класс»; модуль ищется в текущем каталоге.)

## Если бот не подключается

Самые частые причины:

| Что вы видите | Что делать |
|---|---|
| `ConnectionRefused: invalid or revoked bot token` | Токен неверен, заменён кнопкой «Новый токен», бот выключен или удалён. Проверьте токен. |
| `ConnectionRefused: the bot needs designer rights in the room…` | Добавьте логин бота в дизайнеры комнаты (шаг 3). |
| Бот не входит в комнату, а в консоли повторяются предупреждения `сервер отказал в подключении: the bot's owner needs an active PREMIUM subscription; повтор` | У владельца закончился PREMIUM. Отказ временный: бот повторяет попытки сам и подключится после продления подписки. |
| `ConnectionRefused: server refused the connection (HTTP 404)` | Неверный адрес шлюза или бот-API на сервере не включён. Проверьте `SUKARISEBOT_URL`. |

Полная таблица отказов сервера — в разделе [«Ошибки и отказы»](errors.md).
Чтобы увидеть, что происходит внутри, включите журнал:

```python
import logging

logging.basicConfig(level=logging.INFO)
```
